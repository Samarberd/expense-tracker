# Expense Manager
A simple console-based expense management application written in Python.
## Features
- Create a new user or load saved user data
- Store user name and age
- Add purchases to a shopping list
- Delete purchases from the list
- Edit user information
- Calculate total expenses
- Save and load data using JSON
## Technologies
- Python 3
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling
## How to Run
1. Make sure Python 3 is installed.
2. Open the project folder in the terminal.
3. Run the following command:
```bash
python "Expense Manager.py"
```
## Data Storage
User information and shopping lists are stored locally in `user.json`.
The `user.json` file is excluded from version control using `.gitignore`.
